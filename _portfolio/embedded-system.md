Autonomous line-tracing vehicle developed with embedded C on an MSP430 microcontroller.

* Configured low-level hardware peripherals and validated circuit connections against schematics.
* Implemented real-time navigation logic with a finite-state machine (FSM) for motor actuation and sensor tracking.
* Integrated a network communication interface enabling external remote commands.
